# Personal Portfolio Website

A dark, modern, minimal portfolio showcasing my IT support, infrastructure, and software engineering work.

🌐 **Live site:** [vvipwwk.qzz.io](https://vvipwwk.qzz.io)

---

## About

This site brings together my professional experience, technical skills, and the software, hardware, and design projects I've built, from university work to freelance jobs.

## Key Highlights

- **Single-page layout** with smooth-scroll navigation (About, Skills, Projects, Experience, Contact)
- **Responsive design** that adapts to desktop, tablet, and mobile
- **Dark theme** with a purple gradient accent, scroll-reveal animations, and a custom `{}` favicon

## Tech Stack

**This website**

- HTML5, CSS3, JavaScript (vanilla)
- [Bootstrap 5](https://getbootstrap.com/) and [Bootstrap Icons](https://icons.getbootstrap.com/)
- Google Fonts: Space Grotesk and JetBrains Mono

## Project Structure

```
My-portfolio-web-project/
├── index.html      # Main page (markup, styles, and scripts)
└── img
└── README.md
```

## Deployment

Hosted as a static site on a custom domain (`vvipwwk.qzz.io`). Any push to the main branch updates the live site.
